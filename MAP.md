# Repo Map (Authority Boundaries)

**Authoritative layers (in order):**
1. `patent/` — legal spec & claims
2. `architecture/` — technical descriptions aligned to claims
3. `core-ontology/` — definitions, primitives, invariants
4. `embodiments/` — demonstrations / evidence
5. `residue/` — raw inputs, prompts, schemas, samples
6. `writing/` — narrative framing (non-spec)

**Principle:** code is optional evidence; markdown is the canonical substrate.
