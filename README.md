# IAM Core

This repository is structured as a **theory → architecture → embodiment → optional code** system.

- `writing/` — narrative essays and public-facing framing (not legal spec)

- `patent/` — provisional drafts, claims, and traceability

- `architecture/` — technical truth layer (levels, comparisons, pipelines)
- `embodiments/` — worked examples / reduction-to-practice artifacts
- `core-ontology/` — primitives, invariants, glossary
- `residue/` — prompts, schemas, samples (redacted)
- `code/` — prototypes (e.g., iOS ingestion app)

See `MAP.md` for authority boundaries.
