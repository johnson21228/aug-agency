# Agent Stacks

This document describes conventional agent-based system architectures.

## Typical Agent Stack

A standard agent stack includes:
- perception / input layer
- semantic interpretation
- goal inference
- planning
- execution
- feedback optimization

These systems prioritize:
- autonomy
- continuous action
- optimization toward objectives

## Structural Characteristics

- Semantics-first
- Inference-driven
- Optimization-oriented
- Execution-centric

## Failure Mode

Agent stacks fail humans when:
- inferred goals replace explicit intention
- optimization crowds out reflection
- continuity is reduced to episodic state

Agent stacks are effective at acting.
They are not designed to preserve human agency.

## Contrast with IAM

IAM does not compete at the agent layer.
It supports the human side of the loop by preserving continuity and re-entry.

Agents execute.
IAM orients.
