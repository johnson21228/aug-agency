# CAG vs IAM

This document contrasts **Context-Aware Generation (CAG)** with **Intelligent Augmented Memory (IAM)**.

## Context-Aware Generation (CAG)

CAG systems:
- assemble context dynamically
- infer relevance
- generate outputs based on semantic similarity
- treat context as a consumable input

CAG optimizes for response quality within a bounded interaction.

## Intelligent Augmented Memory (IAM)

IAM:
- preserves continuity across interactions
- does not infer relevance
- does not assemble semantic context
- enables re-entry rather than regeneration

IAM treats prior activity as a place to return, not a context to consume.

## Key Difference

| Dimension | CAG | IAM |
|--------|-----|-----|
| Context | Assembled | Preserved |
| Semantics | Required | Avoided |
| Time horizon | Local | Longitudinal |
| Goal | Output quality | Agency support |

IAM is not a generation system.
It is a continuity system.
