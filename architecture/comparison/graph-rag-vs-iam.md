# Graph RAG vs IAM

This document contrasts **Graph-based Retrieval-Augmented Generation (Graph RAG)** with IAM.

## Graph RAG

Graph RAG systems:
- externalize knowledge into graphs
- encode semantic relationships
- retrieve nodes based on query relevance
- generate responses using structured knowledge

These systems prioritize:
- knowledge coherence
- explainability
- semantic coverage

## IAM

IAM:
- does not externalize meaning
- does not encode semantic relationships
- preserves structural continuity only
- relies on human re-engagement for meaning

## Core Distinction

Graph RAG builds **externalized semantic coherence**.

IAM preserves **internalized reasoning continuity**.

Graph RAG answers questions.
IAM preserves the conditions under which questions evolve.

They are orthogonal, not competitive.
