# Atlas Stitching Prompt (Residue)

Purpose:
This prompt is an experimental instrument for exploring how fragmented traces
might be stitched into larger continuity structures ("atlases") without
semantic interpretation.

Scope:
- Used for probing structural relationships
- Used for testing re-entry alignment
- Used for identifying possible region boundaries

Constraints:
- This prompt is not stable
- This prompt is not an API
- Output is not authoritative

Notes:
Results generated using this prompt belong in `residue/samples/`
or may be discarded.

Promotion:
If a stitching pattern proves stable across multiple uses, it may later
inform architectural or ontological definitions.
