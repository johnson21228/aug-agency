# Continuity Ingest Prompt (Residue)

Purpose:
This prompt explores how raw interaction artifacts can be ingested as
non-semantic continuity traces.

Scope:
- Tests explicit capture assumptions
- Probes boundaries between input and interpretation
- Examines time-ordering and adjacency preservation

Constraints:
- No summarization
- No interpretation
- No inference of intent

Notes:
This prompt exists to test ingestion discipline.
Failures are as informative as successes.

Promotion:
Insights may later inform ingestion pipeline documentation,
but this prompt itself is not canonical.
